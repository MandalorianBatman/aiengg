# 1. LLM Basics & Transformer Internals

> **What this session is.** A teaching lecture that builds intuition for LLM terminology and walks through the transformer block-by-block. The lecture's framing throughout is "the model is just predicting the next token" — every concept is anchored back to that single objective.

## Session Goals

1. Build intuition for LLM terminology — the terms that come up in class, team discussions, papers, and blogs.
2. Peel back one layer of the LLM and see what's inside — focus on the **transformer**.

## Concepts Covered

Each concept below has its own page with the canonical definition, analogy, Mermaid diagram, and the lecture's take quote.

### Architecture & Internals

| Concept | One-line summary from the lecture |
|---|---|
| [Large Language Model](../concepts/large-language-model.md) | A neural network trained to predict the next token of an input sequence. |
| [Token](../concepts/token.md) | A unit of text consumed by the model, generated by an algorithm like BPE. |
| [Byte Pair Encoding (BPE)](../concepts/byte-pair-encoding.md) | Greedy compression-style algorithm: merge the most frequent adjacent pair until vocabulary hits a target size. |
| [Vector (Embedding)](../concepts/vector-embedding.md) | A coordinate in a multi-D space (768, 8192) assigned to each token. |
| [Transformer](../concepts/transformer.md) | The internal architecture used by LLMs. Walked through block-by-block rather than defined up front. |
| [Positional Encoding](../concepts/positional-encoding.md) | The mechanism that lets the transformer know the order of tokens in a sequence. |
| [Layer Normalization](../concepts/layer-normalization.md) | The "root-mean-square normalize" step that runs alongside attention and the FFN. |
| [Attention](../concepts/attention.md) | Each token looks at every other token, computes similarity, gets *contextualized*. |
| [Q, K, V (Query, Key, Value)](../concepts/query-key-value.md) | Three vectors per token, computed by three learnable projections. |
| [Masked Attention](../concepts/masked-attention.md) | Upper-triangle mask; turns one sentence into **N training pairs**. |
| [Feed-Forward Network](../concepts/feed-forward-network.md) | Per-token block that derives new features from old ones (same shape in/out). |
| [Linear Layer / LM Head](../concepts/linear-unembedding.md) | Final N × D → N × \|vocab\| mapping that produces next-token probabilities. |
| [Vocabulary](../concepts/vocabulary.md) | The set of tokens the model knows; one row in embedding, one column in unembedding. |
| [N-gram vs LLM](../concepts/n-gram-vs-llm.md) | Both do next-token prediction; LLMs do it with massive learned transformations. |

### Inference & Optimization

| Concept | One-line summary |
|---|---|
| [Context Window](../concepts/context-window.md) | The number of tokens the model can attend to. 1M context ≠ 1M tokens of info. |
| [KV Cache](../concepts/kv-cache.md) | Memoization of K and V vectors — avoids recomputing the N × N similarity matrix each step. |
| [Input vs Output Tokens](../concepts/input-vs-output-tokens.md) | Input = context the model receives; output = what it generates. In typical apps, input > output. |

## Q&A Highlights

| Question | Answer |
|----------|--------|
| What is a vector, really? | A token's coordinate in a high-D space; each dimension is conceptually a feature. |
| How do meaningless BPE tokens cluster? | The model learns "royalty" as a feature, so coronation/kingly/royal cluster. |
| Are LLMs and N-grams the same? | Yes, conceptually — both predict next tokens. LLMs do it with massive transformations. |
| What is the FFN doing? | Deriving new features from old ones (same shape in/out). |
| Why is the context window limited? | Each token attends to all others → quadratic cost. |
| Why three matrices (Q, K, V)? | Mathematically a roundabout way of using the same vector; deep-dive deferred. |

## Key Takeaways

1. **LLM = transformer-stack** predicting next token autoregressively
2. **Tokens** are sub-word units (BPE) mapped to vectors in high-D space
3. **Attention** turns ambiguous vectors into contextualized vectors via Q/K/V similarity
4. **Masked attention** gives N training signals per N-token sentence
5. **Feed-forward** layers transform features into more useful features (same shape in/out)
6. **Linear layer** at the end → probability distribution over vocabulary
7. **KV cache** and **vocabulary size** are critical for performance and cost
